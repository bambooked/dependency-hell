# Dependency Hell — uv 版（発展課題）

## 前提

既存のPythonプロジェクトを引き継ぎましたが、環境構築と実行に問題があります。 **ソースコードは変更せず**、uv を使って `main.py` を正常実行できる状態に復旧してください。

## 目標

リポジトリのルートで以下を実行し、標準出力に `complete` だけが表示さる。

```bash
uv sync
uv run --no-sync python main.py
```

## 修正してよいファイル

- `pyproject.toml`
- `.python-version`
- `uv.lock`（`uv` が生成した場合、コミット可）

上記以外は編集しないでください。特に `main.py`、`data/`、GitHub Actionsは変更禁止です。ファイルの削除・依存ライブラリの置き換えは、許可されたファイル内で行えます。

## 提出

1. このリポジトリをclone(もしくはfork)する。
2. 許可されたファイルだけを修正する。
3. クリーンな環境で `uv sync` と `uv run --no-sync python main.py` を確認し、目標が満たされているか確認する。
4. Pull Requestを作成する。原因・修正方針・実行結果を簡潔に説明する。

合格判定はGitHub Actionsが行います。依存関係の整理についての説明は学びを共有するためのもので、自動採点は `complete` の出力を重視します。
